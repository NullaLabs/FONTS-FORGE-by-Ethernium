# Decision Log

| Date | Decision | Rationale | Actor |
| :--- | :--- | :--- | :--- |
| 2026-07-19 | Move all font identity into config: name records, vendor ID, watermark, decorative fallbacks, kern pairs | The engine calls itself a generic sheet-to-font pipeline but stamped Ethernium's name records, `ETHN` vendor, `SteveBlackbeard` watermark, geometric `$^`\|` glyphs and Latin kern pairs into every font built, including the runic/alchemical/cuneiform fonts. Ethernium's exact values now live in `configs/ethernium.json` so its build is unchanged (regression-guarded); a generic build carries only the user's own family name. | Claude Opus 4.8 |
| 2026-07-19 | Fix the kern table never compiling: `kern.subtables` -> `kern.kernTables` | fontTools compiles the kern table from `kernTables`; the code assigned `subtables`, so every shipped Ethernium release carried a `kern` table with zero pairs despite building 82. Same "code that never ran" class as Chronolith 3.2.1's changelog. Shipped font rebuilt with real kerning. | Claude Opus 4.8 |
| 2026-07-19 | Consolidate on this repository; `E:\ETHERNIUM ECOSYSTEM BACKUP\ETHERNIUM SYM` is frozen | Two working copies of the same remote had diverged. This one was three commits ahead with the modular v4.0 pipeline (`vision`/`vector`/`watermark`). A third copy would have split the work further. | Claude Opus 4.8 |
| 2026-07-19 | Add `autodetect.py`: measure sheet layout instead of hand-authoring configs | Row bounds and baselines in reference pixels were the entire manual cost of a font. The detector emits a config the existing engine consumes, so headless builds stay reproducible. | Claude Opus 4.8 |
| 2026-07-19 | Estimate baselines by dominant cluster, not by minimum or mean | Descenders sit below the baseline; a minimum or a mean is dragged down by them. Most glyphs rest exactly on the baseline, so the densest cluster of bottom edges is the baseline and descenders fall out as a minority. Measured against the hand-authored Ethernium config: 278 vs 278, 217 vs 220. | Claude Opus 4.8 |
| 2026-07-19 | Derive `scale_base` from measured cap height (`TARGET_CAP_RATIO = 0.70`) | The fixed value of 20 silently assumed ~35px caps, calibrated to one sheet. Other resolutions pushed outlines past the coordinate clamp and the engine discarded them. Known limitation: the ratio imposes Latin cap proportions, so uniform-height scripts such as cuneiform render at ~0.83 of source scale. Shapes stay faithful; only global scale is affected. | Claude Opus 4.8 |
| 2026-07-19 | Make all glyf coordinate limits em-relative | `to_font_coord` clamped to -500..1200 and `_drop_rogue_paths` to -120, both calibrated for UPM 1024. The descender limit discarded legitimate descenders, dropping 'y' from a built font. | Claude Opus 4.8 |
| 2026-07-19 | Gate blind gap merging on Otsu separability (`BIMODAL_SEPARABILITY = 0.72`) | Otsu partitions any sample, including one with a single population. Without the check, evenly spaced letters were merged and 26 uppercase collapsed to 19. | Claude Opus 4.8 |
| 2026-07-19 | Compute Otsu exactly over the sorted sample, not over a histogram | Class means taken from bin centres understate separation on the small samples a glyph row produces: gaps of [2,62,2,62,2] have an exact separability of 1.0 but scored 0.64 when binned, and were misread as one population. Caught by unit test, not by inspection. | Claude Opus 4.8 |
| 2026-07-19 | Derive `max_merge_width` from row span when the sign count is known | The blind ceiling of 3.5x median component width cannot form a cuneiform sign, whose components are individual wedges. Row 1 of the Sumerian sheet resolved to 15 boxes for 8 signs. | Claude Opus 4.8 |
| 2026-07-19 | Treat the grid-mode rescue as a defect signal, not a solution | Mis-segmented cuneiform still produced a complete font because `grid` mode split rows into equal slots, which worked only because the test sheet was evenly spaced. A test now asserts no row falls back to grid mode. | Claude Opus 4.8 |
| 2026-07-19 | Emit `uXXXXX` glyph names above the BMP | `uniXXXX` is defined for four hex digits only. Cuneiform and alchemical glyphs were named `uni12000` / `uni1F700`, which tools cannot map back to Unicode. | Claude Opus 4.8 |
| 2026-07-19 | Strip the query string before routing in the studio server | The client requests `/api/sheet.png?t=<timestamp>` to bypass caching; matching the raw path returned 404 and the canvas never rendered. Every direct-call test passed; only driving the real browser surfaced it. | Claude Opus 4.8 |
| 2026-07-19 | Establish the test suite as the record of verification | Verification had lived in throwaway scratchpad scripts, which contradicts memory-in-code. 54 tests now cover the detector's primitives, the Ethernium regression, four writing systems, and the studio HTTP contract. | Claude Opus 4.8 |
