# 🌐 ETHERNIUM FONT

Este directorio contiene los archivos tipográficos definitivos y las interfaces interactivas listas para el usuario final.

---

## 📦 Contenido del Paquete

- **`Ethernium_Sym.ttf`**: Fuente de escritorio TrueType. Haz doble clic en ella para instalarla en tu sistema (Windows/macOS).
- **`Ethernium_Sym.woff`** y **`Ethernium_Sym.woff2`**: Fuentes comprimidas listas para desarrollo web (carga ultra rápida).
- **`preview_font.html`**: Mapa de caracteres y previsualizador de escritorio. Abre este archivo en tu navegador para ver y probar todos los caracteres y símbolos especiales.
- **`unicode_converter.html`**: Convertidor de texto Unicode para redes sociales (Discord, Twitter/X, Instagram, biografías, etc.). Escribe tu texto y cópialo con un solo clic en estilo rúnico/decorativo compatible universalmente sin instalar la fuente.
- **`presentation_generator.html`**: Generador y editor visual premium de espécimen y banners en 1080p. Permite personalizar el tamaño, el brillo neón, el fondo cyberpunk y exportar o copiar al portapapeles directamente para Discord.
- **`logo_emblem.png`**: Emblema rúnico circular oficial utilizado por el generador visual.
- **`glyph_atlas.png`**: Atlas completo de alta resolución que visualiza todos los glifos de la tipografía.

---

## 🚀 Cómo instalar la fuente
1. Haz doble clic en el archivo **`Ethernium_Sym.ttf`**.
2. Haz clic en **Instalar**.
3. ¡Listo! Ya estará disponible en Photoshop, Word, Figma, Illustrator y cualquier software de tu ordenador bajo el nombre **`Ethernium Sym`**.
